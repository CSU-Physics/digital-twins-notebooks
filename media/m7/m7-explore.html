How sure is a validation result?

A simulated twin is tested on held-out runs of five wafers each. Each run's errors share a run effect, so the run is the test unit. Set the twin's true error and the test, then compare the interval with the tolerance. In a simulation the true error is known; in a fab it is not.

The twin and the test

Each wafer's error is a run effect shared by the run's five wafers (60 % of the variance) plus its own (40 %). The interval is MAE ± t(0.975, n − 1) · s / √n over the test units.
