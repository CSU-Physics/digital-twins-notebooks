NumPy arrays and the standard deviation

readings = np.array([999.6, 1000.4, 1000.1,
    999.8, 1000.3, 999.9, 1000.2, 999.7])
readings[0]           # 999.6
readings + 273.15     # every element
readings.mean()       # 1000.0
readings.std(ddof=1)  # 0.293  sample
readings.std()        # 0.274  population
s = √( Σ (xi − x̄)² / (n − 1) )

Python counts positions from 0. The sample SD divides by n − 1; NumPy's default divides by n.

Module 0 · Start here8
Pause and predict

Sample or population: does it matter?

For the 8 readings, the sample SD (divide by n − 1) is 0.293 °C and the population SD (divide by n) is 0.274 °C: a gap of 7%.

Predict: with 60 readings from the same hold, does the gap grow, shrink or stay the same?

It shrinks. The ratio of the two is √(n / (n − 1)): 1.069 for n = 8, but 1.008 for n = 60, under 1%. The choice matters most for small samples. The course uses the sample SD (ddof=1) for readings.

Missing values: leave them out, never fill with zero

Hold period of the example run (61 rows, 1 missing)Mean (°C)Sample SD (°C)
Leave the missing reading out (60 readings)999.5600.430
Repeat the previous reading (forward fill)999.5610.427
Fill it with 0983.17127.98

One zero among 61 readings pulls the mean down by about 1000 / 61 ≈ 16 °C and makes the SD meaningless.

Good habits: count the missing values, say how you handled them, and never let a filled value pass for a measured one.

Moving average: smoothing the hold

yj = (xj + xj+1 + … + xj+w−1) / w
  • n readings give n − w + 1 averages: 60 → 56 for w = 5.
  • Independent noise: the SD falls by about √w.
  • The price: the average lags behind a changing signal.
Module 0 · Start here13
Pause and predict

How much does a 5-point average smooth?

The example hold readings have a sample SD of 0.430 °C.

Predict: the SD of their 5-point moving average.

About 0.430 / √5 ≈ 0.19 °C. The notebook gives 0.175 °C, a ratio of 2.46 rather than 2.24. An SD estimated from 56 overlapping averages has its own scatter, so expect close, not exact.
Module 0 · Start here14
Pause and predict

The price of smoothing

A twin running in real time has only past readings, so it uses a trailing average: at 100 s, the 5-point average uses the readings from 60 to 100 s, centred 20 s in the past.

At 100 s the zone is warming by about 0.7 °C per second. Predict: how far below the current temperature does the average read?

About 0.7 × 20 ≈ 14 °C. Without noise the exact gap is 15.2 °C: the warm-up was steeper in the past. In the hold the level is flat, so the lag costs nothing there; Module 5 meets the same trade-off in the EWMA filter.

Debugging: the planted bug

def moving_average(x, window):
    kernel = np.ones(window)
    return np.convolve(np.asarray(x, dtype=float),
                       kernel, mode="valid")

moving_average(hold_readings, 5)[0]
# 4996.78

Look at the numbers: is 4,997 °C possible for a zone held at 1000 °C?

Test a case you can do by hand: [1, 2, 3, 4, 5, 6] with w = 3 should give [2, 3, 4, 5].

Change one thing, then rerun the cell and every cell that uses it.

In the lab you find and fix this bug. The check cell tests the repaired function on cases you cannot see.
