Holding the thickness on target while the furnace drifts

A simulated furnace runs recipe DRYOX-90 (target 61.2 nm) for 60 runs while its thermocouple bias grows. After each run an EWMA updates the offset d̂ between the monitor wafer and the twin's Deal-Grove prediction, and the recipe rule sets the next oxidation time, within 80 to 100 minutes. The fixed recipe always runs 90 minutes. Both see the same drift and noise.

Furnace and controller

Simplified model: one degree of bias costs 0.52 nm at 90 minutes, as in the course's simulated furnace near 1000 °C. The noise splits into the run's own variation, which the product gets, and the monitor wafer's measurement error.

Two estimators of the same offset

The true offset d (dashed) moves a little from run to run: a steady drift plus random steps. Each run gives one noisy observation (dots). The EWMA blends each observation in with the fixed weight λ; the Kalman filter computes its weight, the gain K, from its settings Q and R and from its own uncertainty P. Both start from the true offset with P = R.
